DESCRIPTION:
Target cell limited model of viral dynamics with an eclipse phase.
Loss of virions due to infection of target cells is included.
Parameters: R0 (basic reproduction number), kI (transfer rate from eclipse to
productively infected cells), delta (loss rate of infected cells),
p (viral production rate), c (viral clearance rate),
V0 (log10 of initial viral load), T0 (initial concentration of target cells).

[LONGITUDINAL]
input = {R0, kI, delta, p, c, V0, T0}

EQUATION:
odeType = stiff
t_0 = 0

; infection rate constant derived from R0 (accounting for loss of virions by infection)
beta = R0*delta*c/(T0*(p - R0*delta))

; initial conditions
T_0  = T0
I1_0 = 0
I2_0 = 0
V_0  = 10^V0

ddt_T  = -beta*T*V
ddt_I1 = beta*T*V - kI*I1
ddt_I2 = kI*I1 - delta*I2
ddt_V  = p*I2 - c*V - beta*T*V

LV = max(log10(max(V, 1e-30)), -5)

OUTPUT:
output = {LV}
table = {T, I1, I2, V}
