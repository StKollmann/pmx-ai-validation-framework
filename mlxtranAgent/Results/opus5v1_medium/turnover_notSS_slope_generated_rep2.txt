DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters (ka, V, Cl) given as regressors. PD: indirect response
(turnover) model with stimulation of the production rate by the drug.
The system is not at steady state at t=0: R(0) = R0 while the
steady-state response Rss is linked to R0 by a linear relationship
Rss = intercept + slope*R0.

[LONGITUDINAL]
input = {ka, V, Cl, R0, intercept, slope, kout, Emax, EC50}

ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
; one-compartment model with first-order absorption
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff

; initial condition (system not at steady state at t=0)
t_0 = 0
R_0 = R0

; steady-state response, linearly related to the baseline response
Rss = intercept + slope*R0

; zero-order production rate constant derived from the steady state
kin = kout*Rss

; stimulation of the production by the drug
Stim = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
