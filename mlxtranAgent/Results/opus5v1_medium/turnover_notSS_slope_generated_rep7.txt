DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters (ka, V, Cl) provided as regressors.
PD: indirect response (turnover) model with stimulation of the production (kin).
The system is NOT at steady state at time 0: R(0) = R0 while the steady-state
response Rss is linearly related to R0 (Rss = intercept + slope*R0).

[LONGITUDINAL]
input = {ka, V, Cl, R0, intercept, slope, kout, Emax, EC50}
ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
; PK part with the pkmodel macro
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff

; Steady-state response, linearly related to the baseline response
Rss = intercept + slope*R0

; Production rate constant consistent with the steady-state response
kin = kout*Rss

; Initial condition: system not at steady state at t=0
t_0 = 0
R_0 = R0

; Stimulation of the production by the drug
Stim = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
