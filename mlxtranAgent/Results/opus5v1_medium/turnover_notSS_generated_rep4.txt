DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
individual PK parameters (ka, V, Cl) given as regressors.
PD: turnover model with stimulation of the production rate by the drug (Emax).
The response is not at steady state at t=0 (R(0) = R0, baseline production
based on the steady-state value Rss).

[LONGITUDINAL]
input = {ka, V, Cl, R0, Rss, kout, Emax, EC50}
ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
; one-compartment model with first-order absorption
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff

; initial condition: response not at steady state at t=0
t_0 = 0
R_0 = R0

; zero-order production rate consistent with steady-state value Rss
kin = kout * Rss

; stimulation of the production by the drug
Stim = Emax * Cc / (EC50 + Cc)

ddt_R = kin * (1 + Stim) - kout * R

OUTPUT:
output = {Cc, R}
