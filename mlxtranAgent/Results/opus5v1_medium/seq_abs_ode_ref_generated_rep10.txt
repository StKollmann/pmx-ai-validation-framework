DESCRIPTION:
Two-compartment PK model with sequential zero-order then first-order absorption.
Doses enter the absorption compartment (Ad) via a zero-order input of duration Tk0,
then drug is absorbed into the central compartment with first-order rate ka.

[LONGITUDINAL]
input = {Tk0, ka, V, Cl, Q, V2}

PK:
; zero-order input of the dose into the absorption compartment Ad
depot(target=Ad, Tk0)

EQUATION:
odeType = stiff

; initial conditions
t_0 = 0
Ad_0 = 0
Ac_0 = 0
Ap_0 = 0

; micro-constants
k   = Cl/V
k12 = Q/V
k21 = Q/V2

; first-order absorption from Ad to central compartment
ddt_Ad = -ka*Ad
ddt_Ac =  ka*Ad - k*Ac - k12*Ac + k21*Ap
ddt_Ap =  k12*Ac - k21*Ap

Cc = Ac/V

OUTPUT:
output = {Cc}
