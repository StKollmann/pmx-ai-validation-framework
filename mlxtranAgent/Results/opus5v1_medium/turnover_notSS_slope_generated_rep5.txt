DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters (ka, V, Cl) provided as regressors.
PD: indirect response (turnover) model with stimulation of production (Emax).
The system is not at steady state at t=0: R(0) = R0, while the steady-state
value Rss is linearly related to R0 (Rss = intercept + slope*R0).

[LONGITUDINAL]
input = {ka, V, Cl, R0, intercept, slope, kout, Emax, EC50}

ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
; PK part with the pkmodel macro
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff

; steady-state response and production rate
Rss = intercept + slope*R0
kin = kout*Rss

; initial condition (not at steady state)
t_0 = 0
R_0 = R0

; stimulation of the production by the drug
Stim = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
