DESCRIPTION: Sequential PK-PD turnover model with stimulation of the production by the drug.
One-compartment PK with first-order absorption, PK parameters given as regressors.
PD not at steady state at time 0 (R(0) = R0, steady-state value Rss).

[LONGITUDINAL]
input = {ka, V, Cl, R0, Rss, kout, Emax, EC50}
ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff
t_0 = 0
R_0 = R0

kin = kout*Rss
E = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + E) - kout*R

OUTPUT:
output = {Cc, R}
