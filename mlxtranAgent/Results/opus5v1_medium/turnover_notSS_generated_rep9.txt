DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters given as regressors. PD: turnover model with stimulation of
the production rate by the drug concentration. The response is not at
steady state at time 0 (R(0) = R0 different from the steady-state value Rss).

[LONGITUDINAL]
input = {ka, V, Cl, R0, Rss, kout, Emax, EC50}

ka = {use=regressor}
V  = {use=regressor}
Cl = {use=regressor}

PK:
; One-compartment model with first-order absorption
Cc = pkmodel(ka, V, Cl)

EQUATION:
odeType = stiff

; Zero-order production rate giving the steady-state value Rss
kin = Rss*kout

; Initial condition (not at steady state)
t_0 = 0
R_0 = R0

; Stimulation of the production by the drug
Stim = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
