DESCRIPTION:
Exposure-response model with effect compartment driven by average concentration (Cavg)
read from the dataset as a regressor, and an Emax response.

[LONGITUDINAL]
input = {E0, ke0, Emax, EC50, Cavg}
Cavg = {use=regressor}

EQUATION:
odeType = stiff

; Effect compartment concentration, initial value at steady state with Cavg=0
t_0 = 0
Ce_0 = 0

ddt_Ce = ke0 * (Cavg - Ce)

; Emax response
E = E0 + Emax * Ce / (EC50 + Ce)

OUTPUT:
output = {E}
