DESCRIPTION:
Two-compartment PK model with sequential zero-order then first-order absorption.
Zero-order input (duration Tk0) into the absorption compartment Ad via the depot macro,
followed by first-order transfer (ka) from Ad into the central compartment Ac.

[LONGITUDINAL]
input = {Tk0, ka, V, Cl, Q, V2}

PK:
; zero-order input of the dose into the absorption compartment Ad over duration Tk0
depot(target=Ad, Tk0)

EQUATION:
odeType = stiff

; initial conditions
t_0 = 0
Ad_0 = 0
Ac_0 = 0
Ap_0 = 0

; first-order absorption from Ad to central compartment, two-compartment disposition
ddt_Ad = -ka*Ad
ddt_Ac = ka*Ad - (Cl/V)*Ac - (Q/V)*Ac + (Q/V2)*Ap
ddt_Ap = (Q/V)*Ac - (Q/V2)*Ap

; central concentration
Cc = Ac/V

OUTPUT:
output = {Cc}
