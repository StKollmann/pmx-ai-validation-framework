[LONGITUDINAL]
DESCRIPTION:
Sequential PKPD turnover model with stimulation of the production by the drug.
One-compartment model with first-order absorption, parameters given as regressors.
Indirect response model, not at steady state at time 0.

input = {ka, V, Cl, R0, intercept, slope, kout, Emax, EC50}

ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
Cc = pkmodel(ka, V, Cl)

EQUATION:
t_0 = 0
R_0 = R0

; Response at steady state, linear relationship with the response at time 0
Rss = intercept + slope*R0

; Zero-order production rate
kin = kout*Rss

; Stimulation of the production by the drug
Stim = Emax*Cc/(EC50 + Cc)

ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
