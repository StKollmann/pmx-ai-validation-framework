DESCRIPTION:
Two-compartment PK model with sequential zero-order then first-order absorption.
Doses enter the absorption compartment (Ad) as a zero-order input of duration Tk0,
then transfer to the central compartment with first-order rate ka.

[LONGITUDINAL]
input = {Tk0, ka, V, Cl, Q, V2}

PK:
; Zero-order input of the dose into the absorption compartment Ad
depot(target=Ad, Tk0)

EQUATION:
; Initial conditions
t_0 = 0
Ad_0 = 0
Ac_0 = 0
Ap_0 = 0

; First-order absorption from Ad into the central compartment
ddt_Ad = -ka*Ad
ddt_Ac = ka*Ad - (Cl/V)*Ac - (Q/V)*Ac + (Q/V2)*Ap
ddt_Ap = (Q/V)*Ac - (Q/V2)*Ap

; Central concentration
Cc = Ac/V

OUTPUT:
output = {Cc}
