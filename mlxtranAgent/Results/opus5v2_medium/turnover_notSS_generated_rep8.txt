DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters (ka, V, Cl) given as regressors. PD: turnover model with
stimulation of the production rate by the drug (Emax model).
The response is not at steady state at t=0 (R(0) = R0 differs from Rss).

[LONGITUDINAL]
input = {ka, V, Cl, R0, Rss, kout, Emax, EC50}
ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
Cc = pkmodel(ka, V, Cl)

EQUATION:
t_0 = 0
R_0 = R0

kin = kout*Rss
Stim = Emax*Cc/(EC50 + Cc)
ddt_R = kin*(1 + Stim) - kout*R

OUTPUT:
output = {Cc, R}
