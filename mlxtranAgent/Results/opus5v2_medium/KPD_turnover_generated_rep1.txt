DESCRIPTION: K-PD model (virtual PK compartment with degradation only) linked to an
indirect response (turnover) model with inhibition of the production (proliferation)
rate described by a sigmoidal Imax function.

[LONGITUDINAL]
input = {k, R0, kdeg, IC50, Imax, gamma}

PK:
; doses enter the virtual K-PD compartment Ak
depot(target=Ak)

EQUATION:
t_0 = 0
Ak_0 = 0
R_0 = R0

; production rate at baseline
kin = R0*kdeg

; virtual concentration (K-PD: no volume, no absorption)
Ck = Ak

; sigmoidal Imax inhibition of the production rate
INH = Imax*Ck^gamma/(IC50^gamma + Ck^gamma)

ddt_Ak = -k*Ak
ddt_R = kin*(1 - INH) - kdeg*R

OUTPUT:
output = {R}
table = {Ck}
