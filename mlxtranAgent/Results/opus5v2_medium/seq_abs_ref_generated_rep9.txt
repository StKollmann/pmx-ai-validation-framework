DESCRIPTION:
Two-compartment PK model with sequential zero-order then first-order absorption.
Dose enters a depot compartment (cmt=1) through a zero-order input of duration Tk0,
then transfers to the central compartment (cmt=2) with a first-order rate constant ka.

[LONGITUDINAL]
input = {Tk0, ka, V, Cl, Q, V2}

PK:
; transfer rate constants for the peripheral compartment
k23 = Q/V
k32 = Q/V2

; depot compartment with zero-order input
compartment(cmt=1, amount=Ad)
absorption(cmt=1, Tk0)

; first-order transfer from depot to central compartment
transfer(from=1, to=2, kt=ka)

; central compartment
compartment(cmt=2, amount=Ac, volume=V, concentration=Cc)
elimination(cmt=2, Cl)

; peripheral compartment (cmt=3) linked to central compartment (cmt=2)
peripheral(k23, k32)

OUTPUT:
output = {Cc}
