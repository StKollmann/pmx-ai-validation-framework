DESCRIPTION:
Target cell limited viral dynamics model with an eclipse phase (non-productively
infected cells I1) and loss of free virions due to infection of target cells.

Parameters:
- R0    : basic reproduction number
- kI    : transfer rate from eclipse phase to productively infected cells
- delta : loss rate of productively infected cells
- p     : viral production rate per infected cell
- c     : viral clearance rate
- V0    : base 10 logarithm of the initial viral load
- T0    : initial concentration of target cells

The infectivity rate beta is derived from R0 accounting for the loss of virions
due to infection: R0 = p*beta*T0 / (delta*(c + beta*T0))

[LONGITUDINAL]
input = {R0, kI, delta, p, c, V0, T0}

EQUATION:
odeType = stiff

; ---- Derived infectivity rate from R0 ----
beta = R0*delta*c / (T0*max(p - R0*delta, 1e-10))

; ---- Initial conditions ----
t_0  = 0
T_0  = T0
I1_0 = 0
I2_0 = 0
V_0  = 10^V0

; ---- ODE system ----
ddt_T  = -beta*V*T
ddt_I1 = beta*V*T - kI*I1
ddt_I2 = kI*I1 - delta*I2
ddt_V  = p*I2 - c*V - beta*V*T

; ---- Output: log10 viral load with lower saturation at -5 ----
LV = max(log10(max(V, 1e-10)), -5)

OUTPUT:
output = {LV}
table = {T, I1, I2, V, beta}
