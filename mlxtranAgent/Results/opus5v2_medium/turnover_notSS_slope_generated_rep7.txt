DESCRIPTION:
Sequential PK-PD model. PK: one-compartment with first-order absorption,
PK parameters (ka, V, Cl) given as regressors.
PD: indirect response (turnover) model with stimulation of the production rate.
The system is not at steady state at t=0: R(0) = R0 while the steady-state
value Rss is linked to R0 by a linear relationship Rss = intercept + slope*R0.

[LONGITUDINAL]
input = {ka, V, Cl, R0, intercept, slope, kout, Emax, EC50}

ka = {use=regressor}
V  = {use=regressor}
Cl = {use=regressor}

PK:
; one-compartment model with first-order absorption
Cc = pkmodel(ka, V, Cl)

EQUATION:
t_0 = 0
R_0 = R0

; steady-state response linearly related to the baseline response
Rss = intercept + slope*R0
kin = kout*Rss

; stimulation of the production by the drug
Stim = 1 + Emax*Cc/(EC50 + Cc)

ddt_R = kin*Stim - kout*R

OUTPUT:
output = {Cc, R}
