[LONGITUDINAL]
DESCRIPTION:
Friberg semi-mechanistic model of chemotherapy-induced myelosuppression.
PK is 1-compartment with first-order absorption (depot macro with ka) and linear elimination.
PD has a proliferating compartment, 3 transit compartments and a circulating compartment.

input = {ka, V, Cl, Circ0, MTT, gam, Emax, EC50}

PK:
; Doses enter a hidden depot; absorption into Ac handled by the macro
depot(target=Ac, ka)

EQUATION:
; ---- Transit rate and system rates ----
ktr = 4/MTT
kprol = ktr
kcirc = ktr

; ---- Initial conditions ----
t_0 = 0
Ac_0 = 0
Prol_0 = Circ0
Tr1_0 = Circ0
Tr2_0 = Circ0
Tr3_0 = Circ0
Circ_0 = Circ0

; ---- PK ----
ddt_Ac = - (Cl/V)*Ac
Cc = Ac/V

; ---- Drug effect (Emax inhibition of proliferation) ----
Edrug = Emax*Cc/(EC50 + Cc)

; ---- Feedback ----
FB = (Circ0/max(Circ,1e-6))^gam

; ---- PD ----
ddt_Prol = kprol*Prol*(1 - Edrug)*FB - ktr*Prol
ddt_Tr1  = ktr*Prol - ktr*Tr1
ddt_Tr2  = ktr*Tr1  - ktr*Tr2
ddt_Tr3  = ktr*Tr2  - ktr*Tr3
ddt_Circ = ktr*Tr3  - kcirc*Circ

OUTPUT:
output = {Cc, Circ}
