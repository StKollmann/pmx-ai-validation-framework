DESCRIPTION:
PKPD model: 1-compartment PK with first-order absorption and lag time, linear elimination
(defined with PK macros). PD: indirect response (turnover) model with inhibition of production.
PK parameters (Tlag, ka, V, Cl) are provided as regressors.

[LONGITUDINAL]
input = {Tlag, ka, V, Cl, IC50, Rin, kout}
Tlag = {use=regressor}
ka = {use=regressor}
V = {use=regressor}
Cl = {use=regressor}

PK:
; 1-compartment model with first-order absorption and lag time
compartment(cmt=1, amount=Ac, volume=V, concentration=Cc)
absorption(cmt=1, ka, Tlag)
elimination(cmt=1, Cl)

EQUATION:
; initial condition of the PD variable at baseline
t_0 = 0
E_0 = Rin/kout

; inhibition of production
inh = Cc/(Cc + IC50)
ddt_E = Rin*(1 - inh) - kout*E

OUTPUT:
output = {Cc, E}
